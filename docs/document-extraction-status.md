# Статус извлечения судовых документов

## Что реализовано

- Оригинальный PDF сохраняется неизменным; текущая версия не перезаписывает решения и не переиндексирует кандидатов после подтверждения.
- Явные главные размерения извлекаются только при наличии единицы измерения.
- Полностью совпадающие кандидаты одного поля и значения объединяются; все найденные страницы и исходные фрагменты сохраняются как свидетельства.
- Разные значения одного поля не объединяются: их необходимо сверить и выбрать.
- Пакетное подтверждение нескольких параметров создаёт одну неизменяемую ревизию модели исходных данных.
- Отдельные подтверждения по одному параметру по-прежнему создают отдельные ревизии.
- Извлечение табличных фрагментов проверяет до 250 страниц-кандидатов, сначала используя линии таблиц, затем текстовую структуру.
- Тип таблицы определяется по характерным заголовкам. Общие слова вроде displacement больше не должны сами по себе превращать таблицу дедвейта в гидростатическую.
- Для страниц без извлекаемого текста формируется предупреждение OCR, если таких страниц не менее половины документа. Это предупреждение о покрытии всего документа, а не точная локализация раздела.
- Полный отчёт анализа сохраняется как производный кэш с номером версии алгоритма. Повторное открытие документа той же версией возвращает кэш, а не перечитывает PDF.

## Ограничения

- OCR изображений и сканированных страниц ещё не реализован.
- Сложные страницы с векторными потоками более 5 MiB пропускаются табличным парсером ради ограничения нагрузки; их номера указываются в отчёте.
- Извлечённые таблицы остаются предварительными фрагментами, а не утверждёнными числовыми наборами данных.
- Текстовая эвристика классификации таблиц может ошибаться. Перед использованием необходимо сверять заголовки и ячейки с оригиналом.
- При изменении алгоритма нужно увеличить версию анализа. Отчёт будет построен заново при следующем запросе; исходный PDF и ранее записанные решения не изменяются.
- Если сохранение кэша не удалось, результат текущего анализа всё равно возвращается, а следующий запрос попробует построить его снова.

## Следующий этап

1. Извлечение табличных данных с устойчивой реконструкцией многострочных заголовков, объединённых ячеек и единиц.
2. OCR и анализ изображений/схем с сохранением координат фрагментов на странице.
3. Нормализация данных в универсальную модель судна с происхождением каждого значения.
4. Отдельная валидация гидростатических, танковых, остойчивостных и прочностных наборов.
