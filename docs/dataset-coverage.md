# Покрытие наборов данных судового документа

Модуль `app.services.dataset_coverage` объединяет текстовый отчёт документа
и предварительно извлечённые табличные фрагменты в единую карту покрытия.

Он нужен, чтобы не считать раздел отсутствующим только потому, что поисковые
слова не встретились в текстовом слое. Например, фрагмент таблицы танков может
быть найден классификатором таблиц, даже если раздел «Танки и вместимости»
не получил текстовых совпадений.

Статусы:

- `TABLE_EVIDENCE_REVIEW_REQUIRED` — есть фрагмент таблицы нужного типа;
- `TEXT_EVIDENCE_REVIEW_REQUIRED` — есть только текстовые указатели;
- `EXTRACTION_INCOMPLETE` — структурное извлечение таблиц не запустилось или
  завершилось ошибкой для всего документа;
- `NO_EVIDENCE_FOUND_NOT_PROVEN_ABSENT` — совпадения не найдены, но отсутствие
  данных не доказано.

Пропущенные по лимиту страницы, сложные векторные страницы и локальные ошибки
разбора показываются отдельно как ограничения документа. Они не переводят все
наборы без совпадений в `EXTRACTION_INCOMPLETE`: например, пропуск схемы танков
не означает, что не удалось извлечь данные о ветровом крене.

Табличные фрагменты дополнительно разделяются по назначению: FSM, поправки
осадки, ветровой кренящий момент, обледенение, креновый опыт, погружение винта
и таблицы дифферента. Это позволяет видеть наличие конкретных источников
отдельно от общего класса «загрузочная таблица». Классификация остаётся
эвристической и не подтверждает корректность извлечённых ячеек.

Это инвентаризация доказательств, а не семантический импорт. Ячейки не
нормализуются, значения не утверждаются и не передаются в расчётный движок.
Перед использованием необходимо проверить оригинал PDF, многострочные
заголовки, единицы, datum, систему координат и страницу-источник. OCR,
графики и геометрия схем остаются отдельными задачами.

Результат `build_dataset_coverage` включён в ответ API
`GET /api/v1/documents/{document_id}/report` и выводится в интерфейсе как
карта покрытия. Следующий этап — семантическое чтение ячеек и связей между
таблицами с сохранением исходных единиц, координат, datum и provenance.
