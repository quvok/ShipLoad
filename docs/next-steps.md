# Следующие этапы

## Выполнено на текущей ветке

- Сводная карта покрытия наборов данных по текстовым указателям и классифицированным табличным фрагментам.
- Отдельные статусы для найденной таблицы, текстового указателя, неполного извлечения и отсутствия совпадений без утверждения об отсутствии данных.
- Вывод карты покрытия в отчёте документа в интерфейсе.

## Дальнейшая последовательность

1. Сохранение проверенной универсальной модели судна как неизменяемой ревизии.
2. Семантический импорт калибровочных таблиц трюмов и танков с многострочными заголовками, единицами, datum и источниками.
3. Преобразование уровня/заполнения в объём, массу, центры тяжести и FSM только по подтверждённым кривым конкретного помещения.
4. Раздельные расчётные модули по фактически доступным наборам данных конкретного судна.
5. OCR/распознавание схем и извлечение данных из графиков с обязательной ручной проверкой.
6. Валидация на нескольких типах судов и независимых эталонных расчётах.

Табличные фрагменты и текстовые совпадения остаются доказательствами для проверки, а не расчётными данными. Данные танкера из тестового документа нельзя переносить на другое судно.
