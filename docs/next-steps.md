# Следующие этапы

## Выполнено на текущей ветке

- Сводная карта покрытия наборов данных по текстовым указателям и классифицированным табличным фрагментам.
- Отдельные статусы для найденной таблицы, текстового указателя, неполного извлечения и отсутствия совпадений без утверждения об отсутствии данных.
- Вывод карты покрытия в отчёте документа в интерфейсе.
- Сквозной расчёт из интерфейса: весовые моменты, гидростатическая интерполяция без экстраполяции, осадки, дифферент, FSM, начальная GM и крен.
- Табличные GZ и динамические площади при наличии исходной KN-кривой; нормативные критерии не подменяются универсальными допущениями.
- Неизменяемая история запусков с полными входами, источниками, результатами и версией метода; повторное открытие и печать расчётного снимка.
- Учебный сценарий по курсовому проекту для воспроизводимого сравнения с контрольными значениями.
- Загрузка нескольких PDF/DOCX прямо в форму расчёта и извлечение из табличного текста LBP, плотности воды, светлого судна, строк загрузочного условия, гидростатики и KN-кривой с источниками.
- Архивирование оригиналов при импорте и обязательная отметка ручной сверки извлечённых данных перед расчётом.

## Дальнейшая последовательность

1. Расширить семантический импорт на разные шаблоны судовых книг и извлекать KN из таблиц cross-curves с согласованием по водоизмещению и дифференту.
2. Связать форму расчёта с неизменяемой ревизией VesselModel и подтверждёнными источниками.
3. Семантически импортировать калибровочные таблицы трюмов и танков с заголовками, единицами, datum и ссылками на страницы.
4. Пересчитывать уровень/заполнение в объём, массу, центры тяжести и FSM только по проверенной кривой конкретного помещения.
5. Добавить конфигурируемые критерии остойчивости, ветер, угол заливания, пределы продольной прочности и сравнение условий.
6. Добавить OCR/распознавание схем и извлечение данных из графиков с ручной проверкой.
7. Независимо валидировать методики и наборы данных на нескольких типах судов.

Извлечённые данные сначала остаются черновиком и требуют сверки с оригиналами. Импортёр поддерживает только распознанные текстовые таблицы и заголовки; он не переносит данные танкера на другое судно и не распознаёт сканы/чертежи.
