# Следующие этапы

## Выполнено на текущей ветке

- Сводная карта покрытия наборов данных по текстовым указателям и классифицированным табличным фрагментам.
- Отдельные статусы для найденной таблицы, текстового указателя, неполного извлечения и отсутствия совпадений без утверждения об отсутствии данных.
- Вывод карты покрытия в отчёте документа в интерфейсе.
- Сквозной расчёт из интерфейса: весовые моменты, гидростатическая интерполяция без экстраполяции, осадки, дифферент, FSM, начальная GM и крен.
- Табличные GZ и динамические площади при наличии исходной KN-кривой; нормативные критерии не подменяются универсальными допущениями.
- Неизменяемая история запусков с полными входами, источниками, результатами и версией метода; повторное открытие и печать расчётного снимка.
- Учебный сценарий по курсовому проекту для воспроизводимого сравнения с контрольными значениями.

## Дальнейшая последовательность

1. Связать форму расчёта с неизменяемой ревизией VesselModel и подтверждёнными источниками, чтобы не переносить исходные значения вручную.
2. Семантически импортировать калибровочные таблицы трюмов и танков с заголовками, единицами, datum и ссылками на страницы.
3. Пересчитывать уровень/заполнение в объём, массу, центры тяжести и FSM только по проверенной кривой конкретного помещения.
4. Добавить конфигурируемые критерии остойчивости, ветер, угол заливания, пределы продольной прочности и сравнение условий.
5. Добавить OCR/распознавание схем и извлечение данных из графиков с ручной проверкой.
6. Независимо валидировать методики и наборы данных на нескольких типах судов.

Табличные фрагменты и текстовые совпадения остаются доказательствами для проверки, а не расчётными данными. Данные танкера из тестового документа нельзя переносить на другое судно.
