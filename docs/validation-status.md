# Validation status

The preliminary loading-calculation flow is connected from the React interface through FastAPI to an immutable calculation snapshot.

Automated checks cover hydrostatic interpolation and refusal to extrapolate, loading-condition outputs against the course-project reference, KN-to-GZ conversion, dynamic-area integration, API persistence/readback and out-of-range inputs.

Software checks do not approve the example vessel, source data, stability criteria or operational use. Independent marine-engineering review and applicable class/flag validation remain required.
