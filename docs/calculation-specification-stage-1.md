# Расчётная спецификация ShipLoad — этап 1

## Основание

Пользовательский курсовой проект `KP_TUS_Gr1_P18_3.docx`, редакция от 15.11.2026:
- раздел 1.2, стр. 6: основные размерения, лёгкое судно и координатный ноль;
- раздел 2, стр. 7–10: суммы масс и статических моментов, свободные поверхности;
- раздел 3, стр. 11–14: гидростатика, осадки, дифферент, крен;
- раздел 4–5, стр. 15–19: корректировка плана балластом и повторный расчёт.

## Координаты

Начало координат: пересечение кормового перпендикуляра и основной плоскости.
- X положительный в нос;
- Y положительный на левый борт;
- Z положительный вверх.

Координатную систему нельзя назначать автоматически по одному названию столбца. В расчёт допускаются только подтверждённые и согласованные координаты.

## Входные данные

- лёгкое судно: масса, LCG, TCG, VCG и отдельный исходный момент для проверки продольной прочности;
- каждая нагрузка: масса, X/Y/Z, свободный момент поверхности;
- LBP;
- плотность забортной воды;
- гидростатическая таблица: объёмное водоизмещение, extreme draft, Xf, Xc, Zm, MCT.

Каждый вход должен иметь ссылку на документ, страницу/таблицу/строку и статус проверки. Программный модуль расчёта получает уже проверенные значения и сам по себе не извлекает и не подтверждает их.

## Формулы, реализованные на этапе 1

1. `Δ = ΣP`; `Xg = Σ(P·X)/Δ`; `Yg = Σ(P·Y)/Δ`; `Zg = Σ(P·Z)/Δ`.
2. `∇ = Δ / ρ`.
3. Свободная поверхность: `δmh = Ix · ρжидкости`; суммарная поправка к VCG `δZg = Σδmh / Δ`; `Zg' = Zg + δZg`.
4. Гидростатические значения dэ, Xf, Xc, Zm, MCT интерполируются по ∇ между соседними строками. Экстраполяция запрещена.
5. По формулам курсового проекта (3.2) и (3.3):
   - `dн = dэ + (LBP/2 − Xf) · 0.01 · (Xg − Xc) · Δ / (LBP · MCT)`;
   - `dк = dэ − (LBP/2 + Xf) · 0.01 · (Xg − Xc) · Δ / (LBP · MCT)`.
6. `Df = dн − dк`; `ψ = 57.3 · Df / LBP`; `dср = (dн + dк)/2`.
7. `h' = Zm − Zg'`; `θ = 57.3 · Yg / h'` (эквивалентно форме через поперечный момент).
8. При наличии KN-кривой с теми же водоизмещением, дифферентом и ссылкой на источник: `GZ(θ) = KN(θ) − Zg' · sin(θ)`. Площадь динамической остойчивости интегрируется трапециями по углу в радианах; для 30° и 40° применяется линейная интерполяция внутри кривой. За диапазон KN экстраполяция не производится.

## Что намеренно не реализовано этим этапом

- распределение жидкого груза по таблицам вместимости и интерполяция центров/свободных поверхностей;
- проверка угла заливания и нормативных критериев IMO/Class, критерий погоды и wind heeling;
- диаграммы допустимого Zg и диаграммы прочности;
- Remes chart / резонансные зоны;
- оптимизация балласта и грузовых операций;
- прочность по продольной балочной модели.

Эти разделы требуют исходных таблиц/диаграмм из судовой Информации об остойчивости и отдельной проверки методик. Отсутствующие значения не подменяются допущениями.

## Ограничение применения

Результат этого модуля — расчётная реализация учебной методики из указанного проекта. Он не является одобренным loadicator и не предназначен для принятия оперативных решений по загрузке судна.
